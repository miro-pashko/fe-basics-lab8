# Лабораторна робота №8 — Пашко М. П., ІП-41, варіант 21

Адаптивна верстка сайту «Locksmith» за макетом варіанту 21 (HTML5, CSS3 та трохи JavaScript для меню, слайдера й форми).

## Як запустити локально

Завантажте або клонуйте репозиторій (`git clone https://github.com/miro-pashko/fe-basics-lab8`) і відкрийте файл `index.html` у будь-якому сучасному браузері. Файли `index.html`, `style.css`, `script.js` і папка `img` мають лежати разом, а для шрифтів Rajdhani та Open Sans (Google Fonts) потрібне підключення до Інтернету — без нього сайт відображається запасними шрифтами.

## Публікація на GitHub Pages

У репозиторії відкрийте **Settings → Pages**, у розділі **Build and deployment** виберіть **Deploy from a branch**, гілку `main` і папку `/ (root)`. Через 1–2 хвилини сайт буде доступний за адресою `https://<ваш-логін>.github.io/<назва-репозиторію>/`.

## Адаптивність

- від 901 px — повна версія, як на макеті;
- до 900 px — меню-бургер, форма «Get a quote» у кілька рядків, послуги у 2 колонки;
- до 768 px — верхній блок і блок «Why choose us» складаються в одну колонку, статистика в 3 колонки;
- до 600 px — телефон переходить у меню, послуги й поля форми в одну колонку;
- до 480 px — товари у 2 колонки.

```
index.html   розмітка сторінки
style.css    стилі та медіазапити
script.js    меню, слайдер у верхньому блоці, перевірка форми
img/         фото та іконки
```
